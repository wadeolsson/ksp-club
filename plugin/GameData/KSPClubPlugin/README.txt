KSP CLUB Plugin v0.1.0
======================

Installation
------------
Copy the KSPClubPlugin/ folder into your KSP GameData/ directory.

  GameData/
    KSPClubPlugin/
      KSPClubPlugin.dll
      PluginData/         ← your player.cfg is stored here (auto-created)

First Run
---------
Load any save. A setup dialog will appear asking for your player ID.
Enter the ID your game master registered for you (e.g. "wade").
This ID is stamped on every vessel you launch so the merge tool knows
who owns what.

What It Does
------------
- Stamps playerID on every vessel you create/launch
- Warns you if you try to use stock Kerbals (Jeb, Val, Bill, Bob)
- Saves ownership data inside your persistent.sfs automatically
